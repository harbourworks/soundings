# Soundings

**Evidence-backed answers to security questionnaires, run locally.**

Soundings scans a project on your own machine and records what it finds: which AI providers it calls, where data is stored and sent, how keys are handled. Answers to a client's security questionnaire are then built from those findings, and anything the code can't tell it becomes a question for you. Your code never leaves your machine.

Status: pre-release, under construction. Nothing is published yet.

Soundings produces drafts. It is not legal advice and does not say that anyone is compliant with anything.
